# 新着ゲームさがし

App Storeの新しいゲームを、スマホで手軽に探せるWebページです。iPhoneのSafariで動きます。

**[ページを開く](https://iranaimeru.github.io/new-games/)**

## できること

- キーワードでゲームを検索（空欄ならゲーム全般から探す）
- 次の条件で絞り込み（「絞り込み」をタップすると開きます）
  - ジャンル（ロールプレイング、パズル、アクションなど）
  - 対応端末（iPhone / iPad）
  - 公開日（7日・30日・90日以内）
  - 無料のゲームだけ
  - 開発者名
- 並び替え（新しい順 / 評価が高い順 / 評価数が多い順）
- 開発者名、評価、容量、価格を一覧で確認
- スクリーンショットを横にスワイプして確認
- タップするとApp Storeのページを開く

## 使い方

1. キーワードを入力する（空欄でもOK）
2. 「検索」を押す
3. 「絞り込み」や並び替えで、条件を変えて見比べる

絞り込みと並び替えは、検索結果の中からすぐに切り替わります。再検索が必要なのは、キーワードを変えたときだけです。

Safariの共有ボタンから「ホーム画面に追加」を選ぶと、アプリのように起動できます。

## 仕組み

Appleが公開している [iTunes Search API](https://performance-partners.apple.com/search-api) を使っています。このAPIには新着順で取得する機能がないため、複数のキーワードで検索し、ゲームだけを残したうえで、公開日などの条件をこのページ側で絞り込んでいます。

## 注意

- 検索キーワードに一致したものだけが表示されるため、新作をすべて拾えるわけではありません。見つからないときは、キーワードを変えたり、絞り込みを緩めたりしてください。
- 新作は評価がまだ付いていないことが多く、評価順では下に並びます。
- 表示される情報はAppleのAPIから取得したもので、内容の正確さは保証できません。
