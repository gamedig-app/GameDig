# 新着ゲームさがし

App Storeの新しいゲームを、公開日が新しい順に探せるWebページです。iPhoneのSafariで動きます。

**[ページを開く](https://ユーザー名.github.io/new-games/)**

## できること

- キーワードでゲームを検索（空欄ならゲーム全般から探す）
- ジャンルで絞り込み（ロールプレイング、パズル、アクションなど）
- 対応端末で絞り込み（iPhone / iPad）
- 無料のゲームだけを表示
- 期間で絞り込み（7日・30日・90日以内）
- スクリーンショットを横にスワイプして確認
- タップするとApp Storeのページを開く

## 使い方

1. ページを開く
2. 必要ならキーワード、ジャンル、端末、期間を選ぶ
3. 「検索」を押す

Safariの共有ボタンから「ホーム画面に追加」を選ぶと、アプリのように起動できます。

## 仕組み

Appleが公開している [iTunes Search API](https://performance-partners.apple.com/search-api) を使っています。このAPIには新着順で取得する機能がないため、複数のキーワードで検索し、結果を公開日の新しい順に並べ替えています。

## 注意

- 検索キーワードに一致したものだけが表示されるため、新作をすべて拾えるわけではありません。見つからないときは、キーワードを増やしたり期間を広げたりしてください。
- 表示される情報はAppleのAPIから取得したもので、内容の正確さは保証できません。
